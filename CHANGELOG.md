# Changelog

## 0.0.1 beta — 2026-11-13

First public testing release: native MuseScore embeds, the complete local OTS editor, playback with pause/resume and note highlighting, automatic following, native copy saving and draft recovery. All runtime resources and legal notices are bundled into the three standard installation files. See [release notes](docs/releases/0.0.1.md) for installation instructions and beta limitations.
