# Changelog

## 0.0.1 — 2026-11-13

Initial desktop release: native MuseScore embeds, the complete local OTS editor, playback with pause/resume and note highlighting, automatic following, native copy saving and draft recovery. All runtime resources and legal notices are bundled into the three standard installation files. See [release notes](docs/releases/0.0.1.md) for installation instructions and known limitations.

The preliminary beta identity was corrected from `MuseScorer` to `musescorer`; the archive folder now matches the permanent ID. Builds and packaging validate the ID before producing release assets.

The regular 0.0.1 release replaces the preliminary beta with all reviewed license, type-resolution and CSS corrections. The README now includes illustrated usage instructions and an example score. Release provenance covers the three individual Obsidian installation assets and the optional manual-install ZIP.
