# MuseScorer 0.0.1

Initial desktop release, published as a regular GitHub release with tag `0.0.1`. The release includes the corrections made during preliminary beta testing. Community directory review and publication are separate from this GitHub release.

The plugin uses the valid lowercase ID `musescorer`. If you downloaded the preliminary package with ID `MuseScorer`, use the updated assets and rename its installation folder to `musescorer`, keeping `drafts/` intact.

## Included

- Native MSCZ/MSCX embeds with a scrollable page view or all pages vertically, separated by small gaps.
- Hover controls, native playback, pause/resume, note highlighting and automatic score following.
- The complete original OTS_WebEditor notation interface in an Obsidian tab, native copy saving and local draft recovery.
- A self-contained three-file distribution: the engine, editor, fonts, soundfont and licenses are compressed inside main.js. No additional runtime downloads are required.

## Release corrections

- The plugin ID and archive folder use the valid permanent ID `musescorer`.
- GitHub recognizes the GPLv3 license; original copyright, font exceptions and other legal notices remain available offline.
- React/Node type resolution and typed adapter checks were corrected.
- Editor styles use standard CSS; Tailwind registration occurs at build time without changing the generated editor interface.
- The illustrated README includes installation, both embed modes, playback, editing, saving and a downloadable example score.

## Install

Requires Obsidian Desktop 1.7.2 or newer.

Download **MuseScorer.zip** and extract its `musescorer` folder into `<Vault>/.obsidian/plugins/`. The three supplied program files are `main.js`, `manifest.json` and `styles.css`; no additional runtime files are required. Enable **MuseScorer** in Settings → Community plugins. For an existing manual installation, replace these three files and reload the plugin; preserve `drafts/` if you need existing recovery snapshots.

Alternatively, download the three individual assets into `<Vault>/.obsidian/plugins/musescorer/`.

Example:

````markdown
```musescore
path: "Scores/Example.mscz"
view: page
```
````

Use `view: full` for all pages vertically.

## Known limitations

- `main.js` is approximately 40 MB and exceeds Sync Standard's per-file limit. Install separately on each desktop device. Engine/editor initialization is deferred, but the large bundle still has a load and memory cost.
- Mobile is not supported. The native wrapper requests a 512 MiB initial WASM heap, with additional memory for scores, audio and fonts.
- Performance mode and website-only cloud/AI services are unavailable. Normal local editor and playback features are included.
- Saving creates a new native score copy; original source scores are preserved. Drafts restore with a fresh undo history.
- Open in MuseScore uses the operating system's file association. Rendering and playback themselves do not require the MuseScore desktop application.
- The plugin ID and installation folder are `musescorer`. GitHub publication does not establish Community directory approval.

## Credits and validation

Built on [OTS_WebEditor by OurTextScores and its contributors](https://github.com/OurTextScores/OTS_WebEditor), the MuseScore engine and the official Obsidian sample plugin. Use **Show credits and licenses** in the command palette for the bundled legal notices.

The three-file build passed strict TypeScript, lint, fourteen tests and an isolated installation test in the development vault, including native editing, audible playback/highlighting, pause/resume, both following modes, native copy saving and draft recovery. The build also validates the plugin ID before packaging. Testing does not establish compatibility with every score or system.
